# 资料卡演示 使用手册

## App 信息

- 名称：资料卡演示
- 包名：bot.coati.protocol.fixture
- 观察版本：1
- 语言环境：zh-CN

## App 用途
- 用于浏览资料卡。

## 页面索引
- 首页｜识别：顶部资料卡标题，中部卡片列表，底部设置Tab｜入口：启动进入
- 设置页｜识别：顶部设置标题，下方选项列表｜入口：首页底部设置Tab

## 页面详情
### 首页
- 识别：顶部资料卡标题，中部卡片列表，底部设置Tab。
- 功能：首页用于浏览资料卡，底部设置Tab进入设置页。

### 设置页
- 识别：顶部设置标题，下方选项列表。
- 功能：调整显示选项；左上返回回到首页。

## 页面导航
- 首页底部设置Tab → 设置页。

## 弹窗与恢复
- 尚无已验证经验。
